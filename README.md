# Visual Speech Synthesizer

A Python-based speech synthesizer that generates vowel and consonant sounds while displaying synchronized mouth animations. This project combines audio synthesis with visual feedback to create an interactive speaking program.

## Overview

This speech synthesizer uses formant synthesis to create vocal sounds and displays corresponding mouth shapes in real-time using Pygame. It can generate a variety of vowels and consonants, with support for vibrato, pitch changes, and duration control.

## Features

- **Sound Generation**: Creates vocal sounds using formant synthesis, combining fundamental frequencies with harmonic overtones
- **Visual Feedback**: Displays animated mouth shapes that correspond to different phonemes
- **Interactive Control**: Allows real-time input of sound sequences with various modifiers
- **Modifiable Parameters**: Supports adjustments to:
  - Sound duration
  - Pitch
  - Vibrato
  - Timing between sounds
